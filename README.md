# THE MOTH IN THE MACHINE

### An Immersive Three-Level 3D Mechanical Laboratory

An interactive 3D laboratory experience built using Next.js, Three.js, and React Three Fiber. Explore a futuristic research facility, discover a mysterious mechanical moth, and observe its animated energy systems.

## Project Overview

**The Moth in the Machine** is a futuristic 3D laboratory concept featuring a mysterious mechanical organism inside a multi-level research facility.

The laboratory is divided into three interconnected levels, each representing a different part of the machine.

## Laboratory Levels

### Level 01 – The Mechanical Shell
- Industrial laboratory architecture
- Metallic structures and support columns
- Mechanical equipment
- Industrial warning lights

### Level 02 – The Living Engine
- Central energy reactor
- Rotating reactor rings
- Energy generators
- Glowing transmission pipes
- Animated energy particles

### Level 03 – The Moth Core
- Mechanical moth with animated wings
- Specimen containment chamber
- Glowing reactor environment
- Interactive specimen discovery panel

## Key Features

- Interactive 3D laboratory environment
- Three-level navigation system
- Animated mechanical moth
- Rotating energy reactor
- Animated energy transmission
- Mouse-based camera rotation and zoom
- Interactive specimen information panel
- Cinematic opening screen
- Keyboard navigation
- Responsive user interface

## Controls

| Key / Action | Function |
|---|---|
| 1 | Navigate to Level 01 |
| 2 | Navigate to Level 02 |
| 3 | Navigate to Level 03 |
| Enter | Enter the laboratory |
| Escape | Close specimen panel |
| Mouse Drag | Rotate the 3D view |
| Mouse Scroll | Zoom in and out |
| Click Moth | Discover specimen information |

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd moth-in-the-machine
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

To create a production build:

```bash
npm run build
```

## Project Purpose

This project demonstrates an immersive 3D laboratory model combining mechanical architecture, interactive visualization, animation, and user interaction.

The mechanical moth and its specimen readings are fictional elements created for this conceptual experience.
